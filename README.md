<h1 align="center">HAVOC PANEL</h1>
<p align="center"><b>A mod panel for Gorilla Tag — glass UI, live game mods, ESP & more.</b></p>

---

## About

Havoc is a desktop panel that connects to your headset and injects a runtime
agent into Gorilla Tag — giving you a full mod menu with a glassmorphism UI,
theme engine, and an integrated auto-updater.

## Features

- **Glass UI** — frosted panels, aurora header, animated toggles & sliders
- **6 themes** + a fully custom color mode
- **Movement** — pull mod, speed boost, high gravity, local scale
- **Combat** — tag aura, hand snap, PSA
- **Players** — game mods, detection tools, lobby scan (ping / move speed)
- **Visuals** — tracers, box ESP, name tags
- **Presets** — save & load your whole setup locally
- **Auto-updater** — one-click updates with changelogs built in

## Download

Head to the [**Releases**](../../releases) page and grab the latest `Havoc.exe`.

> Windows may show a SmartScreen warning on first run —
> click **More info → Run anyway**.

## Setup

1. Put the headset and your PC on the **same Wi-Fi**, plug USB in once
2. Push & start **frida-server** on the headset (root required)
3. Launch **Gorilla Tag**, then hit **attach + inject** in the panel

Your key unlocks the panel — it's tied to your machine.

## Updating

Havoc checks for updates on launch. When a new version is out, a pulsing
**UPDATE** button appears in the title bar — one click downloads, installs
and restarts on the latest build.

## Config

Settings, presets and logs are stored next to the exe:
`config.json` · `presets/` · `dump.cs`
